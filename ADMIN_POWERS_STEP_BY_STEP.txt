💾 WHERE YOUR CHANGES ARE STORED

Browser localStorage
├─ Variable: adminChanges
├─ Stores: Last 50 edits
├─ Contains: Old content, new content, timestamp, page URL
├─ Persists: Across page refreshes
└─ Clears: When you click "Clear Browser Data"

Session Storage  
├─ Variable: sm_bioNotes_adminSession
├─ Stores: Admin login status
├─ Persists: Until browser tab closes
└─ Used: To keep you logged in while browsing

⚠️  Important:
   These are LOCAL to YOUR browser only.
   To sync across multiple devices/people:
   - Use admin.html → Backup/Restore feature
   - Export JSON of changes
   - Share and import on other devices

🐛 TROUBLESHOOTING

PROBLEM: "⚙️ Options button not showing"
─────────────────────────────────────────
Solutions:
  ✓ Refresh page (Ctrl+R or Cmd+R)
  ✓ Clear browser cache
  ✓ Close and reopen browser
  ✓ Try different browser
  ✓ Check: Is admin-powers.js file in same folder as HTML?
  ✓ F12 → Console → Look for error messages


PROBLEM: "Password doesn't work"
─────────────────────────────────────────
Check:
  ✓ Password is: bismilla@1 (exact, case-sensitive)
  ✓ No spaces before/after
  ✓ Check Caps Lock is OFF
  ✓ Try typing in Notepad first to verify


PROBLEM: "Edit mode won't activate"
─────────────────────────────────────────
Try:
  ✓ Refresh the page
  ✓ Make sure button shows "👑 Admin" (not ⚙️ Options)
  ✓ Click the button again
  ✓ Open browser console (F12) for errors
  ✓ Try again on a different page/course


PROBLEM: "Changes not saving"
─────────────────────────────────────────
Check:
  ✓ localStorage is enabled (not in private mode)
  ✓ Browser tab is same as page you're editing
  ✓ Clicked "💾 Save" button (not just "X" Cancel)
  ✓ No error message appeared
  ✓ Try again - might be temporary glitch


PROBLEM: "Lost my changes"
─────────────────────────────────────────
Check:
  ✓ localStorage not cleared (Settings → Clear Data?)
  ✓ Session not expired (browser tab still open?)
  ✓ Browser didn't crash
  ✓ Review activity log: F12 → Console →
     JSON.parse(localStorage.getItem('adminChanges'))

🔄 ACTIVITY LOG - View Your Edits

How to see what you've edited:

1. Open browser console: F12 key
2. Go to "Console" tab at top
3. Paste this code:
   ────────────────────────────────
   JSON.parse(localStorage.getItem('adminChanges')).forEach(log => {
     console.log(log.timestamp + ' | ' + log.newContent.substring(0,50))
   })
   ────────────────────────────────
4. Press Enter
5. See list of all your recent edits with timestamps

Each entry shows:
  - Timestamp (when you made the change)
  - Start of new content (first 50 characters)
  - Page URL where change was made
