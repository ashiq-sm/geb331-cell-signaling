## Actions

| Action | Location |
|--------|----------|
| Edit question | Manage Questions → Edit |
| Add question | + New Question → Create |
| Delete question | Manage Questions → Delete |
| Edit set | Manage Sets → Edit |
| Add set | + New Set → Create |
| Delete set | Manage Sets → Delete |
| Edit course | Manage Courses → Edit |
| Add course | + New Course → Create |
| Delete course | Manage Courses → Delete |
| Backup | Settings → Backup button |
| Restore | Settings → Restore button |

## Keyboard Shortcuts

- **Ctrl+S** / **Cmd+S**: Save in modal (use Save button)
- **Esc**: Close modal
- **Tab**: Navigate fields

## File Management

**Backup File Format**:
- Name: `bionotes-backup-YYYY-MM-DD.json`
- Contains: All courses, sets, questions, logs
- Size: ~50-100KB typically

**Restore Steps**:
1. Settings → Data Management
2. Click "Restore from Backup"
3. Select .json file
4. Confirm

## Important Notes

- ✅ All edits saved to localStorage
- ✅ Data persists across sessions
- ✅ Activity logged automatically
- ⚠️ Create regular backups
- ⚠️ Password is default - CHANGE IT!
- ⚠️ Deletions are permanent
- ⚠️ Clear data requires double confirmation

## Troubleshooting

**Forgotten password**: Reset browser localStorage
**Lost data**: Restore from backup file
**Changes not showing**: Refresh page
**Slow performance**: Try smaller datasets
**Can't login**: Check console (F12)
