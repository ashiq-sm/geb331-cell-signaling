# Admin Powers - Quick Usage Guide

## 🎯 What is This?

Admin Powers adds a **live editing panel** directly to any course page. No separate admin dashboard needed!

## 🚀 Quick Start (3 Steps)

### Step 1: Open Any Course Page
Click on any course from the home page:
- GEB331 (Cell Signaling)
- GEB334 (Oncology & Virology)
- GEB335 (Fermentation Tech)
- GEB341 (Aquaculture)
- GEB343 (Bioprocess Engineering)

### Step 2: Click "⚙️ Options" Button
In the **top-right corner** of the course page, you'll see:
```
⚙️ Options
```

### Step 3: Login with Admin Password
When you click Options, a login modal appears:
```
🔐 Admin Login
Enter admin password to unlock editing

[Password input field]
[Unlock]  [Cancel]
```

**Password:** `bismilla@1`

## 👑 After Login

Once logged in, the button changes to:
```
👑 Admin
```

And shows a menu with two options:
```
✏️ Edit Mode - Enable live content editing
🚪 Logout   - Exit admin mode
```

## ✏️ Edit Mode Features

### How to Edit
1. Click **"✏️ Edit Mode"** from the menu
2. Click any text on the page to edit it
3. A textarea appears with your content
4. Modify the content
5. Click **"💾 Save"** to save, or **"✕ Cancel"** to discard

### What You Can Edit
- ✅ Course titles and descriptions
- ✅ Topic/set headings
- ✅ Question text
- ✅ Answer content
- ✅ Any other visible text
- ✅ Markdown formatting supported!

### Visual Feedback
- Editable content highlights in **blue** when you hover
- **Toast notifications** confirm your actions
- Real-time updates on the page

## 📝 Markdown Support

All edited content supports **markdown**:

```markdown
**Bold text**
*Italic text*
# Heading 1
## Heading 2
- Bullet list
1. Numbered list
> Block quote
`code`
| Table | Header |
```

## 🔐 Security & Sessions

✅ **Login Features:**
- Password-protected access
- Session persists across page refreshes
- Clear logout function
- Only you see edit buttons

✅ **Session Duration:**
- Stays logged in until you close the browser tab OR
- Click "🚪 Logout" from the admin menu
- Each browser is independent

## 📊 Activity Tracking

All your edits are logged with:
- ✅ What you changed
- ✅ Old content vs new content
- ✅ Exact timestamp
- ✅ Which page it was on

**View activity log in browser:**
1. Open browser console (F12)
2. Type: `JSON.parse(localStorage.getItem('adminChanges'))`
3. See all your edits!

## 🔄 Workflow Examples

### Example 1: Fix a Typo (30 seconds)
```
1. Open course page
2. Click ⚙️ Options → Login
3. Click ✏️ Edit Mode
4. Find the typo, click to edit
5. Fix it
6. Click 💾 Save
✅ Done! Change is live immediately
```

### Example 2: Edit Multiple Questions (5 minutes)
```
1. Login once via Options
2. Click ✏️ Edit Mode
3. Edit question 1 → Save
4. Edit question 2 → Save
5. Edit question 3 → Save
6. Click ⚙️ → 🚪 Logout when done
✅ All changes saved!
```

### Example 3: Add New Content
```
1. Click any section to edit
2. Add your markdown content
3. Include formatting, lists, code blocks
4. Save
✅ Formatted content appears immediately!
```

## 💾 Data Persistence

Where are changes stored?
- **Browser LocalStorage** - Persists across sessions
- **Activity Log** - Tracks all edits
- **Automatic Backup** - Last 50 edits kept

⚠️ Important: Changes stay in your browser. To sync across devices, use the **admin.html** backup/restore feature.

## ⚠️ Important Notes

### Password Management
- Default: `bismilla@1`

## 🐛 Troubleshooting

### "Options button not showing"
- Refresh the page (F5)
- Check browser console for errors (F12)
- Verify admin-powers.js file is in the same folder

### "Edit mode not working"
- Make sure you're logged in (button should say "👑 Admin")
- Try clicking a larger text element first
- Check browser console for JavaScript errors

### "Changes not saving"
- Check that localStorage is enabled
- Try a different browser
- Look for browser storage warnings
- Try incognito/private mode

### "Forgot password"
- Default is `bismilla@1`
- If changed, check the `admin-powers.js` file
